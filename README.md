# 즐거운 테트리스

초등 5~6학년용으로 만든 재미있는 브라우저 테트리스 게임입니다.

## 기능
- 1단계부터 10단계까지 구성
- 각 단계마다 블록 낙하 속도가 빨라짐
- 각 단계마다 다른 배경 음악 재생
- 점수, 삭제한 줄, 단계, 다음 블록 미리보기 제공
- 시작, 일시정지, 다시 시작 버튼 제공

## 실행 방법
1. 폴더를 열고 index.html 파일을 브라우저로 실행합니다.
2. 게임 시작 버튼을 누르면 플레이할 수 있습니다.

## 조작법
- 좌우 방향키: 이동
- 위쪽 방향키: 회전
- 아래쪽 방향키: 빠르게 떨어뜨리기
- 스페이스바: 바로 떨어뜨리기
- P: 일시정지
